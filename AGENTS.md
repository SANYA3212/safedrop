# SafeDrop — правила для агентов (Codex и др.)

SafeDrop — P2P-приложение для Windows: файлы, чаты, группы, звонки (WebRTC) напрямую между ПК, обычно поверх Radmin VPN/LAN. Tauri 2 (Rust) + WebView2, интерфейс — чистый JS без фреймворков. Лицензия MIT + Commons Clause (продавать нельзя). Автор — Саня; отвечай ему по-русски.

## Где что
- `src-tauri/src/main.rs` — команды Tauri; `signal.rs` — сигнальный канал (TCP 47832, TLS, одна JSON-строка на соединение, `process_frame`); `transfer.rs` / `quic.rs` — файлы (TCP 47831), докачка; `tls.rs` — ключи устройств, взаимный TLS, запомненные ключи (`pins.json`); `updsig.rs` — подпись обновлений; `state.rs` — структуры и пути файлов.
- `src/app.js` — весь интерфейс (ES-модуль, 6000+ строк), `src/index.html`, `src/styles.css`, `src/tauri-shim.js` (демо-режим в браузере).
- `build-release.bat` (Windows: exe + NSIS + подпись установщика).
- `ident.rs` — один компьютер = один контакт: адреса с одним ключом устройства (`tls::pin_of`, у `sd-` — сам ID) склеиваются в `Peer.ips`; входящее сводится к первичному адресу (`canon` в начале `process_frame` и приёма файлов), исходящее идёт по живому адресу (`route` в `tls::connect`). Новые места, где контакт ищется по адресу, — через `ident::attach`/`canon`, а не `peers.get(ip)` по адресу соединения.
- Режим «через сервер»: клиент — `src-tauri/src/relay.rs` (адреса контактов `sd-<ID>`, связь с сервером, `server.json`), сервер для Linux — отдельный пакет `server/` (`main.rs` — каналы и вход, `turnsrv.rs` — TURN для звонков, `proto.rs` — протокол, общий с клиентом через `#[path]`; `install.sh` и `safedrop-server.service` — установка). Описание и установка — `docs/server.md`. Сервер проверять `cargo test --release` в `server/`.

- Linux-версия не развивается и из этой ветки убрана. Всё, что по ней сделано (Electron-оболочка, пакеты Arch, AppImage, WebKit с WebRTC, скрипты сборки), лежит в ветке `linux-archive`. Код под `#[cfg(target_os = "linux")]` в Rust оставлен как есть: в Windows-сборку он не попадает.

## Обязательно
- **Каждый коммит дописывает `CHANGELOG.md`** в `## [Не выпущено]` (`### Добавлено` / `### Исправлено` / `### Безопасность`), по-русски, по-человечески, как в существующих записях. Сообщения коммитов — на английском.
- **Версию не менять** без просьбы. Версия живёт в `src-tauri/Cargo.toml`, `src-tauri/Cargo.lock` (пакет `safedrop`) и `src-tauri/tauri.conf.json` (включая имя ресурса `safedrop-shell-<версия>.dll`); новая версия — всегда выше последней выпущенной. Ничего не пушить и не публиковать без просьбы.
- **Русский текст — только UTF-8.** Не править `app.js` через PowerShell heredoc (ломает кириллицу); правки — точечные, без переформатирования.
- **Проверка JS:** `app.js` — ES-модуль, проверять копию: скопировать в `*.mjs` и `node --check`.
- **Проверка Rust:** `cargo check --release` и `cargo test --release` в `src-tauri`. В песочнице Codex на Windows `cargo` не запускается (нет доступа к `dlltool.exe`) — тогда пиши Rust особенно аккуратно (заимствования через `MutexGuard`, типы, импорты) и прямо скажи, что не проверял.
- **Новые поля в сохраняемых/сетевых структурах — с `#[serde(default)]`**: старые версии и старые файлы должны читаться.
- **Сетевой протокол обратно совместим**: новый кадр — новый вариант `Frame` с `#[serde(rename = "...")]`; старые клиенты его игнорируют. Всё, что пришло из сети, проверять: размер, формат, что отправитель имеет право (см. `sender_identity`, `sender_chats`, `source_in_group` в `signal.rs`).
- Не дублировать функции; при удалении элемента интерфейса убирать ссылки на него в JS. Настройки звонков сохранять сразу при переключении (как `saveMicProcessingSettings`). «Сбросить всё» (`factory_reset`) должно чистить всё новое, что хранится (файлы и localStorage).
- Не трогать бэкапы `B:\Projects\1\...` и `B:\Projects\safedrop_before_0.3.19`; не откатываться на 0.3.16; Steam не возвращать.
- Не публиковать личные данные: IP друзей, ID устройств, аватарки. Закрытый ключ подписи (`%USERPROFILE%\.tauri\safedrop-update.key`) в репозиторий не класть.

## Безопасность, которую нельзя ослаблять
- `tls.rs`: подпись рукопожатия проверяется по-настоящему (`verify_tls13_signature`); контакт с запомненным ключом — только TLS с тем же ключом, без отката на открытый текст. Не возвращать «принять любой сертификат».
- Обновления ставятся только с верной подписью (`updsig.rs`), без кнопки «всё равно установить».
- Через сервер (`relay.rs`, `tls.rs`): канал к `sd-<ID>` — только TLS, ключ собеседника обязан совпасть с ID (и на входе, и на выходе); ключ сервера запоминается и без подтверждения не меняется; режимы не смешиваются. TURN сервера (`turnsrv.rs`) пересылает только между своими адресами — не превращать его в открытый ретранслятор.
- Встроенный браузер (`ytbrowse.rs`): системе отдаются только `mailto:`/`tel:`; у окна сайта нет IPC.
- Картинки и аватарки из сети — только через `safeImg`/`is_data_image`; пользовательские строки в HTML — через `esc`.
