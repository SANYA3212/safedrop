# SafeDrop 0.3.27

### Исправлено
- **Окно браузера было пустым и ничего не искало** («окно браузера закрыто»): стартовая страница была `data:`-адресом, а Tauri без отдельной опции такие страницы не создаёт — оставалась только верхняя панель. Теперь стартовая страница — обычный файл приложения; если страница всё же не откроется, окно закрывается с понятной ошибкой, а не висит пустым.
- Сайт или собеседник больше не может увести окно браузера на служебные адреса приложения (`tauri.localhost` и т. п.).

### Изменено
- **Чат в браузере — панель справа во всю высоту окна** (кнопка «Чат» в панели, счётчик новых сообщений): вся переписка звонка, Enter — отправить, Shift+Enter — новая строка. Строка «Написать в звонок…» убрана.

## Установка
Скачайте `SafeDrop_0.3.27_x64-setup.exe` ниже и запустите поверх старой версии.
