# SafeDrop 0.3.33

Основная версия для Windows и Linux. Собирает всё, что было в пробных 0.3.31–0.3.33: ключи устройств и шифрование с обеих сторон, подпись внутри установщика, свой аудиоплеер, исправленную отправку картинок. Отправка картинок между двумя ПК ещё не проверялась.

### Исправлено
- **Скриншоты и картинки в чате не доходили до собеседника**, хотя текст доходил (с 0.3.31). Теперь отправитель ждёт, пока собеседник всё дочитает, а SafeDrop больше не присылает данные, из-за которых случался обрыв.
- Мог обрезаться конец файла, отправленного без подтверждения (например, обновления).
- При звонке появлялось «RNNoise не загрузился»: теперь шумодав RNNoise снова работает.
- Обновление от друга ставится тихо, с полосой прогресса, и SafeDrop перезапускается сам.

### Добавлено
- Три вида аудиоплеера в настройках чата: «Волна», «Компактный» и «Системный».
- Подпись обновления внутри установщика: делиться нужно одним `.exe`.
- Сборка 0.3.33 для Linux: пакет Arch и AppImage.

Подробности по каждой версии — в `CHANGELOG.md`.

## Установка на Windows
Скачайте `SafeDrop_0.3.33_x64-setup.exe` ниже и запустите поверх старой версии. Или отправьте обновление другу прямо из SafeDrop: 0.3.31 и новее его примут.

## Установка на Linux
**Arch, готовые пакеты:** скачайте оба `.pkg.tar.zst` и выполните:

```
sudo pacman -U webkit2gtk-4.1-webrtc-2.54.2-1-x86_64.pkg.tar.zst safedrop-0.3.33-1-x86_64.pkg.tar.zst
sudo pacman -S --needed gst-plugins-bad libnice gst-plugin-rsaudiofx
```

Если `webkit2gtk-4.1-webrtc` уже стоит с 0.3.30, достаточно пакета `safedrop`. Обычный WebKit из Arch собран без WebRTC, без него звонков нет.

**Arch, из исходников:** `packaging/arch/webkit2gtk-4.1-webrtc` (около часа сборки), затем `packaging/arch/safedrop` — в каждой папке `makepkg -si`.

**Без установки:** `SafeDrop_0.3.33_x86_64.AppImage` — сделайте исполняемым и запустите, WebKit с WebRTC уже внутри. Собран на Arch, на старых дистрибутивах может не запуститься.

На Linux SafeDrop не обновляется сам: новую версию ставьте пакетом. Порты: TCP 47831 (файлы) и 47832 (чаты, звонки).
