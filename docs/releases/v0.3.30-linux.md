# SafeDrop 0.3.30 для Linux

Первая сборка SafeDrop под Linux. Это та же версия 0.3.30, что и для Windows, плюс поддержка Linux. Собрана и проверена на Arch Linux.

### Что работает
- Передача файлов и докачка, чаты, группы, контакты, автопоиск в сети, темы, встроенный браузер.
- Звонки, камера и демонстрация экрана — только с WebKit, собранным с WebRTC (см. ниже). Соединение и канал данных проверены, звонок между двумя ПК пока не проверялся.
- Автозапуск (`~/.config/autostart`), уведомления, отправка папок (нужен `zip`).

### Чего нет на Linux
- Обновления через SafeDrop: новую версию ставьте пакетом.
- Пункта «Отправить в SafeDrop» в меню Проводника, кнопки Firewall и страниц «Параметров Windows» — они скрыты.

### Почему нужен свой WebKit
WebKit из репозиториев Arch и Ubuntu собран без WebRTC, без него звонков нет совсем. `webkit2gtk-4.1-webrtc` — тот же WebKitGTK 2.54.2, собранный с `ENABLE_WEB_RTC=ON`. Он заменяет системный `webkit2gtk-4.1`.

## Установка на Arch

**Готовые пакеты (быстро):** скачайте оба `.pkg.tar.zst` ниже и выполните:

```
sudo pacman -U webkit2gtk-4.1-webrtc-2.54.2-1-x86_64.pkg.tar.zst safedrop-0.3.30-1-x86_64.pkg.tar.zst
sudo pacman -S --needed gst-plugins-bad libnice gst-plugin-rsaudiofx
```

**Из исходников:** в ветке `linux` лежат `packaging/arch/webkit2gtk-4.1-webrtc` (около часа сборки, 16 ГБ памяти хватает) и `packaging/arch/safedrop` — в каждой папке `makepkg -si`.

**Без установки:** `SafeDrop_0.3.30-linux_x86_64.AppImage` — сделайте исполняемым и запустите. WebKit с WebRTC уже внутри. Собран на Arch, на старых дистрибутивах может не запуститься.

Порты: TCP 47831 (файлы) и 47832 (чаты, звонки). Если включён брандмауэр — откройте их.
