# SafeDrop 0.3.35

Главное — микрофон, динамики и веб-камера в AppImage на Linux.

### Исправлено
- **Linux, AppImage: SafeDrop не видел ни микрофона, ни динамиков, ни веб-камеры**, хотя в системе всё работало. Загрузчик AppImage подменял папку плагинов GStreamer на папку внутри образа, а плагинов там нет: WebKit оставался без PipeWire, PulseAudio и камеры. Теперь SafeDrop в AppImage сам возвращает системные плагины и держит свой кэш плагинов (`~/.cache/safedrop`), не трогая общий системный. Пакет для Arch этой ошибки не имел.

Всё из 0.3.34 на месте. Подробности — в `CHANGELOG.md`.

## Установка на Windows
Скачайте `SafeDrop_0.3.35_x64-setup.exe` ниже и запустите поверх старой версии. Или отправьте обновление другу прямо из SafeDrop: 0.3.31 и новее его примут.

## Установка на Linux
**Arch, готовые пакеты:**

```
sudo pacman -U safedrop-0.3.35-1-x86_64.pkg.tar.zst
sudo pacman -S --needed gst-plugin-pipewire gst-plugins-bad libnice gst-plugin-rsaudiofx
```

Звонкам нужен WebKit с WebRTC: если `webkit2gtk-4.1-webrtc` ещё не стоит, поставьте и его (файл ниже, `sudo pacman -U webkit2gtk-4.1-webrtc-2.54.2-1-x86_64.pkg.tar.zst`). `gst-plugin-pipewire` нужен, если звуком управляет PipeWire (почти все современные Arch).

**Arch, из исходников:** `packaging/arch/webkit2gtk-4.1-webrtc` (около часа сборки), затем `packaging/arch/safedrop` — в каждой папке `makepkg -si`.

**Без установки:** `SafeDrop_0.3.35_x86_64.AppImage` — сделайте исполняемым и запустите, WebKit с WebRTC уже внутри. Плагины GStreamer (в том числе для PipeWire) берутся из системы.

Перед запуском новой версии закройте старую полностью (трей → «Выйти»). На Linux SafeDrop не обновляется сам. Порты: TCP 47831 (файлы) и 47832 (чаты, звонки).
