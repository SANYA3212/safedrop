# SafeDrop 0.3.32 (untested — не проверено)

**Пробная версия.** Собрана, прошла автотесты, но между двумя ПК ещё не проверялась. Если что-то сломалось, можно вручную поставить 0.3.31 или 0.3.30.

Сделано вдвоём, Claude и Codex: каждый проверял работу другого.

### Добавлено
- **Свой аудиоплеер** для голосовых, аудиофайлов и прослушивания записи перед отправкой: теперь он в цветах темы, а не белая капсула браузера. В «Настройки → Чат → Аудиоплеер» три стиля: «Волна» (по умолчанию, с волной у голосовых), «Компактный» и «Системный». Скорость 1× / 1,5× / 2×; одновременно играет только одна запись.
- **Подпись обновления внутри установщика.** Делиться нужно одним `.exe`, файла `.sig` рядом больше нет.

### Исправлено
- В 0.3.31 при звонке появлялось «RNNoise не загрузился — включён встроенный шумодав WebRTC»: файл шумодава не попал в сборку. Теперь RNNoise снова работает.
- Обновление от друга открывало обычный мастер установки вместо тихой установки. Теперь видна только полоса прогресса, после неё SafeDrop перезапускается сам.

### Совместимость
- С 0.3.31 обновляется как обычно: отправьте обновление из SafeDrop, друг на 0.3.31 его примет.
- Друзья на 0.3.26–0.3.30 продолжают соединяться по шифрованному каналу.

## Установка
Скачайте `SafeDrop_0.3.32_x64-setup.exe` ниже и запустите поверх старой версии. Подпись встроена в сам файл, SafeDrop проверит её при обновлении от друга.
