# SafeDrop 0.3.34

Главное — микрофон на Linux с PipeWire.

### Исправлено
- **Linux: микрофон не работал с PipeWire.** Список микрофонов был пуст, а звонок давал «Микрофон: Invalid constraint» или «Микрофон заблокирован». WebKit ищет микрофоны через GStreamer, а для PipeWire ему нужен плагин (Arch: `gst-plugin-pipewire`, Ubuntu: `gstreamer1.0-pipewire`). Теперь SafeDrop сам замечает, что плагина нет, объясняет это и предлагает поставить его одной кнопкой.
- Одинаковые всплывающие сообщения больше не складываются стопкой.
- Linux: выпадающие списки в настройках больше не белые с нечитаемым текстом.

### Добавлено
- Linux: в «Звонки и звук» → «Звук» видно, кто управляет звуком (PipeWire или PulseAudio) и через что SafeDrop берёт микрофон. Если чего-то не хватает, там же есть команда и кнопка «Установить»: пароль спросит сама система.

Всё из 0.3.33 на месте. Подробности — в `CHANGELOG.md`.

## Установка на Windows
Скачайте `SafeDrop_0.3.34_x64-setup.exe` ниже и запустите поверх старой версии. Или отправьте обновление другу прямо из SafeDrop: 0.3.31 и новее его примут.

## Установка на Linux
**Arch, готовые пакеты:**

```
sudo pacman -U safedrop-0.3.34-1-x86_64.pkg.tar.zst
sudo pacman -S --needed gst-plugin-pipewire gst-plugins-bad libnice gst-plugin-rsaudiofx
```

Звонкам нужен WebKit с WebRTC: если `webkit2gtk-4.1-webrtc` ещё не стоит, поставьте и его (файл ниже, `sudo pacman -U webkit2gtk-4.1-webrtc-2.54.2-1-x86_64.pkg.tar.zst`). `gst-plugin-pipewire` нужен, если звуком управляет PipeWire (почти все современные Arch).

**Arch, из исходников:** `packaging/arch/webkit2gtk-4.1-webrtc` (около часа сборки), затем `packaging/arch/safedrop` — в каждой папке `makepkg -si`.

**Без установки:** `SafeDrop_0.3.34_x86_64.AppImage` — сделайте исполняемым и запустите, WebKit с WebRTC уже внутри. Плагин для PipeWire всё равно нужен в системе.

После установки плагина закройте SafeDrop полностью (трей → «Выйти») и запустите снова. На Linux SafeDrop не обновляется сам. Порты: TCP 47831 (файлы) и 47832 (чаты, звонки).
