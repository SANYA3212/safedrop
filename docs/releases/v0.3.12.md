# SafeDrop 0.3.12

Ранняя сборка линейки 0.3: файлы, чат, звонки и демонстрация экрана. Подробный список изменений этой версии не сохранился.

## Установка
Скачайте `SafeDrop_0.3.12_x64-setup.exe` ниже и запустите. Нужен WebView2 (есть в Windows 10/11). Порты: TCP 47831 и 47832.
